## About

I'm a Computer Science & Engineering student at Mangalore Institute of Technology & Engineering (CGPA 7.95/10), currently interning across full-stack development, AI/ML, and cybersecurity. This site is my introduction — who I am, what I've built, and how to reach me.

## Features

- Terminal-inspired hero section with a boot sequence and typewriter role animation
- Fully responsive layout — desktop, tablet, and mobile
- About, Skills, Projects, Internship Experience, Education, Certifications, and Achievements sections
- Project cards with real performance metrics pulled from my own repos (RMSE, accuracy, F1-score)
- Animated scroll reveals and 3D tilt effects on project cards
- Client-side validated contact form
- One-click resume download (PDF embedded directly in the page)
- Interactive particle/constellation background

## Tech Stack

- HTML5
- CSS3 (custom properties, glassmorphism, animations — no framework)
- Vanilla JavaScript (no libraries or build step)

Everything lives in a single self-contained `index.html` file — no dependencies to install, no build process. Just open it in a browser or drop it on any static host.

## Deployment

This project is deployed as a static site. To run it yourself:

```bash
git clone https://github.com/ashishshetty074-byte/Ashish-Portfolio.git
cd Ashish-Portfolio
# open index.html directly in a browser, or serve it locally:
python3 -m http.server 8000
```

It can also be deployed instantly to any static host (Netlify, Vercel, GitHub Pages) by uploading `index.html` — no configuration needed.
